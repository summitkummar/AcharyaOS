# 🎓 AcharyaOS Pro — The Teacher's OS

A premium, 100% offline digital assistant built for Indian teachers. Manage classes, students, attendance, diary, marks, and more — all in one place, without any internet or API dependencies.

## ✨ Features
- 📊 **Dashboard**: Quick stats, weekly attendance chart, and recent activity.
- 👥 **Classes & Students**: Full CRUD with roll numbers, subjects, rooms, and parent contacts.
- ✅ **Smart Attendance**: One-tap P/A/L marking, calendar date picker, and "Mark All Present".
- 📖 **Diary & Homework**: Track daily topics, descriptions, and assignments.
- ⭐ **Marks Tracker**: Record exam scores with automatic percentage and color-coded grades.
- 🗓️ **Timetable**: Period-wise schedule for all 6 working days.
- 📝 **Notes**: Quick reminders and important notes.
- 📈 **Reports**: Detailed attendance and marks summaries, printable format.
- 🌐 **14+ Indian Languages**: Hindi, English, Bengali, Marathi, Telugu, Tamil, Gujarati, Urdu, Kannada, Odia, Malayalam, Punjabi, Assamese, Nepali.
- 🌙 **Dark Mode**: Eye-friendly theme for night use.
- 💾 **Backup & Restore**: Export all data to JSON and restore anytime.
- 📱 **PWA**: Installable on mobile as a real app (Add to Home Screen).

## 🛠️ Tech Stack
- HTML5, CSS3 (Custom Properties, Flexbox/Grid)
- Vanilla JavaScript (No frameworks, no libraries except Tailwind via CDN for UI and FontAwesome for icons)
- LocalStorage for offline data persistence
- Service Worker for PWA/offline capabilities
